# manners.txt

robots.txt told machines where not to go. manners.txt tells them how to behave.

House rules for every AI. **A commons by Chiibitsu Labs**: proposed and stewarded by Chiibitsu Labs,
written with everyone who proposes a rule.

- [`manners.txt`](./manners.txt): the file itself (draft v0.1). The page renders this file directly, so they can't drift apart.
- People write a personal never-list with [Mine.](../mine/) (`mine.txt`). Makers publish `/manners.txt` at their root. Agents read both.

## The tally

People can give items from their Mine. list to the commons (opt-in, per item, no name). Each gift is a public
GitHub issue titled `[mine] …` containing `<!-- mine-commons v1 -->`. The manners page counts items across
**open** issues; when 5 or more people keep the same thing, it shows as a candidate rule. To remove spam,
close the issue.

## Propose a rule

Open an issue with the [manners rule template](https://github.com/chiibitsu/labs/issues/new?template=manners-rule.md).
A rule gets in when it fits on one line, a 12-year-old understands it, it protects people rather than companies,
and you could imagine your grandmother asking for it.
