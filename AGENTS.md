# Rules for agents

These files add no rules beyond the sources they point to. This repo takes `chiibitsu/vibeOS:templates/claude-md.md`, at vibeOS's published head, as its standing orders until it has some of its own. Read that file in full before your first edit.

Read `chiibitsu/vibeOS:AGENTS.md` too, every session, from "## Reviewing a change" onwards. Rules for agents start there, and they apply to you.

This repo is public. The public-repo line in "Credit on GitHub" (`chiibitsu/vibeOS:templates/claude-md.md`) applies: no session links, not in a PR description, a commit trailer or a comment. Nothing private goes in this repo.

`CLAUDE.md` here points to the same places.
